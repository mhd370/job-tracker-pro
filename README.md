# Job Tracker Pro 🚀

A modern React application to track, manage, and organize job applications in one place.

## 🔗 Live Demo

https://starlit-pegasus-56183c.netlify.app/

## 🔗 GitHub Repository

https://github.com/mhd370/job-tracker-pro

---

## ✨ Features

- Add, edit, and delete job applications
- Search and filter applications by status
- Smart sorting (follow-up priority & latest applications)
- Dark / Light mode with persistent settings
- User feedback with Snackbars and confirmation dialogs
- Export applications to CSV
- Fully responsive (mobile-friendly navigation)
- Persistent data using LocalStorage

---

## 🛠️ Built With

- React (Create React App)
- React Router
- Context API
- Material UI (MUI)
- JavaScript (ES6+)
- Netlify

## ⚙️ Getting Started

```bash
git clone https://github.com/mhd370/job-tracker-pro.git
cd job-tracker-pro
npm install
npm start

```

### Build for production

```bash
npm run build
```
